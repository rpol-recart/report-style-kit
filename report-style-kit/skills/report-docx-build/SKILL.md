# Сборка отчёта .docx из манифеста

## Триггер

`content-manifest.json` прошёл линт текста (`scripts/lint_text.py --manifest`, код 0).
Собирать непролинтованный манифест запрещено — FAIL уйдёт в отчёт.

## Команда

```bash
python3 scripts/build_report.py --manifest content-manifest.json --profile work/style-profile.json --template work/template.docx -o отчёт.docx
```

Скрипт строит документ на базе `work/template.docx`: титульный блок из `meta`
по паттерну `title_block` профиля, заголовки стилями Heading 1–3, блоки манифеста
санкционированным маппингом (thesis/lead_in/formula → Normal, bullets/verdict →
List Bullet, table → зарегистрированный стиль таблиц, figure → подпись + картинка +
пояснение). Стиль наследуется от шаблона — дрейф оформления невозможен.

## Коды выхода

| Код | Значение | Что делать |
|---|---|---|
| 0 | Сборка успешна | Перейти к линту собранного отчёта (`skills/report-style-lint/SKILL.md`). |
| 2 | Ошибка манифеста (некорректный JSON или нарушение схемы) | Читать путь к проблеме в сообщении (например `sections[0].blocks[3]: …`), исправить **манифест** и перезапустить. Скрипт не править. |
| 4 | Отсутствуют файлы картинок (список в выводе) | Добавить указанные PNG в `materials/charts/` либо убрать соответствующие figure-блоки из манифеста; пересобрать. |
| 3 | Не найден входной файл (манифест/профиль/шаблон) | Проверить пути команды — все пути относительные, от текущего каталога. |

После успешной сборки скрипт печатает сводку: число секций, блоков по типам,
таблиц и картинок (включая пропущенные).

## Правило

`work/template.docx` и `work/style-profile.json` **не редактировать** — они
генерируются скриптом извлечения и являются эталоном стиля. Любое желание
«подправить шаблон» — признак ошибки в манифесте: исправляй манифест.
