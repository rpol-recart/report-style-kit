# План содержимого: черновики → content-manifest.json

## Триггер

Есть `materials/` (outline.md, черновики, числа, charts/ с описаниями) и
выкуренный `work/styleguide.md`. Результат шага — `content-manifest.json`
для `scripts/build_report.py`.

## Правила разворота черновиков

1. **outline → section_blueprint.** Порядок и названия разделов берутся по
   `section_blueprint` из `work/style-profile.json` (структура образца);
   отсутствующие в образце разделы формируются по черновикам, но сохраняют
   стиль соседних. Ручная нумерация разделов — в тексте заголовка
   (`"heading": "2. Используемые данные"`).
2. **Каждый эксперимент = Цель → Метод → Результаты → Интерпретация**
   (4 блока: thesis, thesis/formula, table, thesis). Результаты оформляются
   таблицей по шаблону из `profile.table_templates` (например,
   `metrics_comparison`), числа приводятся с контекстом: Δ vs baseline,
   проценты, единицы измерения.
3. **Каждый график = figure-блок.** caption: `«Рис. N. <что изображено>»`
   (сквозная нумерация, точка после номера); explanation: «что изображено →
   что видно → вывод». PNG берётся из `materials/charts/`, путь относительный.
4. **Тезис-абзац = 2–5 предложений**, безлично (никаких «я/мы/вы»), тезис —
   первое предложение, далее контекст и числа.
5. **Термины — только из глоссария** (`work/glossary.md`): латинские токены,
   которых нет в глоссарии, дадут предупреждение линта (glossary-warn).
6. **Числа ТОЛЬКО из materials.** Отсутствующее число не выдумывать —
   поставь маркер `"$unresolved"`: линт обязан дать FAIL, после чего
   оркестратор спросит пользователя.
7. **Выводы = verdict-буллеты с числами** (снижение MAE на столько-то %,
   сколько ванн улучшилось), без новых фактов.

## Схема манифеста

Мини-пример всех 7 типов блоков (полный контракт — `schemas/content-manifest.schema.json`):

```json
{
  "meta": {
    "title": "Прогнозирование криолитового отношения (CR)",
    "subtitle": "Отчёт за квартал",
    "project": "internal-cr-pred-2025q3",
    "version": "V9 (per-pot Kalman Filter)",
    "period": "2025-09-01 — 2026-02-01"
  },
  "sections": [
    {
      "heading": "1. Аннотация",
      "level": 1,
      "blocks": [
        { "type": "thesis",
          "text": "Криолитовое отношение CR = NaF / AlF3 — ключевой параметр электролита алюминиевого электролизёра, определяющий ход технологического процесса. Настоящий отчёт описывает расчёт CR по данным за квартал." },
        { "type": "lead_in",
          "label": "Бизнес-вопрос:",
          "text": "Какое значение CR в каждом электролизёре и насколько точен прогноз по сравнению с лабораторным анализом?" },
        { "type": "formula",
          "text": "x_pred = x + β_temp_drift · (ΔT_bath / Δt) · Δt" },
        { "type": "bullets",
          "items": [
            "Factor_rz: rolling z-score электрического Factor c EWM-сглаживанием.",
            "Fluor_lag84: интегрированная масса AlF3 (кг) в окне 24 ч с лагом 84 ч.",
            "Bath_Temp: точечное значение температуры ванны (порог ≤ 48 ч)."
          ] },
        { "type": "table",
          "template": "metrics_comparison",
          "header": ["Метод", "Avg MAE", "Δ vs baseline", "Pots улучшились"],
          "rows": [
            ["V8a (global baseline)", "0.0385", "—", "—"],
            ["V9 (per-pot KF)", "0.0338", "−12.2 %", "16 из 16"]
          ] },
        { "type": "figure",
          "caption": "Рис. 1. Истина vs предсказание — сравнение трёх методов.",
          "image": "materials/charts/fig1_pred_vs_true.png",
          "explanation": "Изображены ряды истина/прогноз для трёх методов → предсказание V9 плотнее следует истине → per-pot калибровка снижает ошибку." },
        { "type": "verdict",
          "text": "Per-pot оптимизация KF (V9) даёт устойчивое снижение MAE: −8.9 % в среднем по сравнению с глобальным baseline V8a, улучшение на всех 16 ваннах." }
      ]
    }
  ]
}
```

Смысловые примеры каждого типа взяты из эталонного отчёта: thesis — аннотация;
lead_in — «Бизнес-вопрос:»; formula — коррекция дрейфа температуры; bullets —
раздел 2.3 (подготовка признаков); table — шаблон `metrics_comparison`;
figure — «Рис. 1»; verdict — итог эксперимента V9.

## Типовые ошибки

| Ошибка | Как исправить |
|---|---|
| Сленг («фидбек», «деливери», «чекнуть», «апдейт») | Заменить нейтральным русским: «отзыв», «результат этапа», «проверить», «обновить». |
| «мы» / «я» / обращение к читателю («мы проанализировали») | Безличная форма: «проанализировано», «получено», «результаты показывают». |
| Число без источника (взято «по памяти») | Только числа из `materials/`; отсутствующее — `"$unresolved"` и вопрос пользователю после FAIL линта. |
| Тезис в конце абзаца | Тезис — первым предложением, далее обоснование. |
| Английская фраза вне глоссария | Убрать или заменить; доменные термины брать из `work/glossary.md`. |
