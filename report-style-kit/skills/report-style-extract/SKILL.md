# Извлечение профиля стиля из образца

## Триггер

Есть образец отчёта (`.docx` прошлого квартала), нет `work/style-profile.json`.

## Команда

```bash
python3 scripts/extract_profile.py --sample образец.docx --outdir work/
```

Скрипт детерминирован: шрифты, кегли, поля, микротипографика и шаблоны таблиц
считываются из образца, ничего не придумывается.

## Что создаётся

| Артефакт | Содержимое |
|---|---|
| `work/style-profile.json` | профиль стиля: page, style_roles, title_block, block_patterns, microtypography, table_templates, section_blueprint, glossary_terms |
| `work/template.docx` | чистый шаблон: тело образца очищено, стили/тема/нумерация/поля сохранены — база сборки |
| `work/styleguide.draft.md` | черновик стайлгайда: тон, структура абзацев, числа и типографика, легенда блоков, таблицы |
| `work/glossary.draft.md` | черновик глоссария: латинские термины образца с частотами и примерами |
| `work/slang-blacklist.txt` | копия базы анти-сленга с пометками «легально в образце» для встреченных терминов |

## Курирование (шаг 2 конвейера)

Черновики генерируются автоматически — их нужно выкурить руками и сохранить как
`work/styleguide.md` и `work/glossary.md`:

1. **title_block**: сверь первые три абзаца титульной страницы (`size_pt`, bold,
   italic, alignment в профиле) с титульной страницей образца визуально.
2. **table_templates**: просмотри список шаблонов. Безликие имена `table_template_N`
   переименуй в осмысленные — **только в styleguide.md** (это имена для человека);
   имена в `style-profile.json` не меняются, сборка ориентируется на них.
3. **glossary**: выкини мусорные токены (`done`, обрывки вроде `kf-`, служебные
   `vs`/`avg`, если они не часть домена) — оставь настоящую доменную лексику.
4. Поправь формулировки в styleguide.md: примеры типографики и легенды блоков
   должны быть понятны исполнителю без доступа к образцу.

## При странном образце

- **Нет стилей Heading 1/2** → СТОП: образец не годится как эталон стиля,
  сообщи пользователю и не пытайся продолжать конвейер.
- **0 таблиц** → предупреждение пользователю: `table_templates` будут пусты,
  табличные блоки в манифесте придётся описывать только заголовками.
