# Styleguide (draft) — CR_Predictor_Report.docx

> Черновик сгенерирован автоматически — курайте перед использованием.

## Тон

Первое лицо не используется (вхождений 1-го лица: 0). Отчёт — безличная констатация фактов.

## Структура абзацев

Тезис-первое-предложение: абзац открывается выводом, затем контекст и числа.
Пример тезис-абзаца из образца:

> Проект: internal-cr-pred-2025q3  |  Версия модели: V9 (per-pot Kalman Filter)
Период данных: 2025-09-01 — 2026-02-01  |  Дата отчёта: 2026-04-26
