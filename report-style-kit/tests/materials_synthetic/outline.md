# Outline — синтетический квартальный отчёт (project: synthetic-cr-pred-2026q3)

## Аннотация
Итог эксперимента E1: сравнение global baseline и wide grid. Ключевые числа —
в numbers.json (MAE до/после, доля улучшенных ванн).

## 1. Контекст
Модель прогноза CR в контуре управления; точность прогноза → качество
рекомендаций. Вопрос заказчика — см. черновик ниже.

## 2. Эксперимент E1
- Цель: сравнить Global V8a и V9 wide по MAE на лабораторных событиях.
- Метод: один корпус данных, per-pot оптимизация по расширенной сетке KF.
- Результаты: таблица по шаблону metrics_comparison из numbers.json;
  график charts/scatter.png (истина vs прогноз).
- Интерпретация: равномерность улучшения по ваннам.

## 3. Выводы
Verdict-буллеты с числами: Δ MAE, доля улучшенных ванн, отсутствие смещения.
Новых фактов вне materials/ не добавлять.
